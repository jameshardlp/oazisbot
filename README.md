# oazisbot
Chat bot originally belonging to the chat "OAZIS"

## Режим контента

Источник постов переключается командой `/mode`. Одновременно работает
**ровно один** режим:

| Значение | Что публикуется |
|---|---|
| `streamers` (по умолчанию) | посты про стримеров: текст от DeepSeek + ссылка на клип |
| `memes` | случайный мем из каналов-источников (скачивание, при необходимости перекодирование через FFmpeg) |

`/mode memes` действует сразу: планировщик стримеров гасится, вместо него
поднимается планировщик мемов. Перезапуск не нужен, выбор сохраняется в
`bot_settings.json`.

Переменная окружения `CONTENT_MODE` задаёт только режим при **первом** запуске,
пока `bot_settings.json` ещё не создан; дальше решает `/mode`. Недопустимое
значение — ошибка на старте с кодом выхода 1, чтобы опечатка не приводила
к молчаливому запуску не того планировщика.

```bash
CONTENT_MODE=memes python bot.py
```

Режим `memes` требует установленного `ffmpeg` в `PATH` — без него видео уйдёт
в канал без перекодирования (Telegram может его не принять).

## Админские команды

Доступны владельцу (`OWNER_ID`) и второму админу `1361723521` — список задан
в `config.py` (`ADMIN_IDS`). Настройки пишутся в `bot_settings.json`
и переживают перезапуск; файл создаётся сам, в репозиторий не попадает.

| Команда | Что делает |
|---|---|
| `/mode` | показывает текущий режим контента |
| `/mode memes` \| `/mode streamers` | переключает режим на ходу, без перезапуска |
| `/interval` | показывает интервал между автопостами |
| `/interval 90` | ровно 90 минут между постами |
| `/interval 60 180` | случайный интервал от 60 до 180 минут |
| `/postnow` | немедленно публикует мем из каналов-источников (в любом режиме, таймер не сдвигает) |
| `/sources` | список каналов, откуда берутся мемы |
| `/sources add <канал> [...]` | добавить канал (принимает `name`, `@name`, `t.me/name`) |
| `/sources del <канал> [...]` | убрать канал |
| `/sources reset` | вернуть список по умолчанию |
| `/schedule` | текущие настройки: режим, канал, интервал, источники |

Новый интервал применяется сразу: планировщик просыпается и отсчитывает время
до следующего поста заново. Диапазон — от 1 минуты до недели; меньше 5 минут
бот примет, но предупредит про флуд-лимиты Telegram.

Канал, который не удалось прочитать через `t.me`, всё равно добавляется — в
ответе будет пометка. Так временная недоступность `t.me` не мешает настройке.

## Переменные окружения

Обязательная: `BOT_TOKEN`.
Основные остальные: `CHANNEL_ID`, `OWNER_ID`, `CONTENT_MODE`, `DEEPSEEK_API_KEY`,
`YOUTUBE_API_KEY`, `FREEKASSA_*`, `AURAPAY_*`. Полный список — в `config.py`.

Проверить конфигурацию: `python config.py`.
